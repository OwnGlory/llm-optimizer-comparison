# Сравнение AdamW, Muon и Hybrid Muon+AdamW при полном дообучении Qwen2.5-0.5B

## 1. Аннотация

В работе реализован и экспериментально проверен воспроизводимый конвейер полного дообучения модели `Qwen/Qwen2.5-0.5B` на наборе данных `Elriggs/openwebtext-100k` с тремя стратегиями оптимизации:

1. AdamW;
2. Muon с резервным AdamW-обновлением для вспомогательных параметров;
3. послойный Hybrid Muon+AdamW.

Сравнение выполнено по четырём основным критериям:

- время обучения;
- максимальное потребление памяти графического процессора;
- сходимость обучения;
- итоговое качество модели на наборах PIQA, ARC-Easy, ARC-Challenge, WinoGrande и HellaSwag.

Для всех методов выполнено полное дообучение: все `494,032,768` параметров модели остаются обучаемыми. Для каждого запуска сохраняются конфигурация эксперимента, журналы обучения на каждом шаге оптимизатора, контрольная точка модели, отчёт проверки журнала, графики и результаты оценки качества.

Основной результат: в текущей постановке AdamW остаётся самым быстрым по времени шага, Muon демонстрирует минимальное потребление памяти, а Hybrid Muon+AdamW даёт промежуточный компромисс по скорости и памяти при сопоставимом качестве на downstream-наборах.

## 5. Краткое описание алгоритмов

### 5.1 AdamW

AdamW используется как базовая стратегия оптимизации для всех обучаемых параметров модели. Оптимизатор хранит оценки первого и второго моментов градиента и применяет развязанное весовое затухание.

Упрощённая структура обновления:

```text
m_t = beta1 * m_{t-1} + (1 - beta1) * g_t
v_t = beta2 * v_{t-1} + (1 - beta2) * g_t^2
w_t = w_{t-1} - lr * m_hat / (sqrt(v_hat) + eps)
w_t = w_t - lr * weight_decay * w_t
```

### 5.2 Muon

Muon применяется к двумерным матричным параметрам Transformer-слоёв. Для каждой выбранной матрицы оптимизатор выполняет накопление импульса, нестеровскую поправку и ортогонализацию обновления с помощью итераций Ньютона—Шульца.

Упрощённая структура обновления:

```text
B_t = momentum * B_{t-1} + G_t
U_t = G_t + momentum * B_t
O_t = NewtonSchulz(U_t, steps=5)
W_t = (1 - lr * weight_decay) * W_{t-1} - lr * O_t
```

Параметры, не подходящие для матричной ортогонализации, обновляются через резервное AdamW-обновление.

### 5.3 Hybrid Muon+AdamW

Hybrid-режим реализует послойное разделение модели:

| Часть модели | Оптимизатор |
|---|---|
| Transformer-слои 0–11, выбранные двумерные матричные веса | Muon |
| Transformer-слои 12–23 | AdamW |
| Эмбеддинги, смещения, веса нормализации, `lm_head` и прочие вспомогательные параметры | AdamW |

Такой режим проверяет компромисс между меньшим потреблением памяти Muon и стабильностью AdamW на верхних слоях модели.

### 10.3 Интерпретация оценки качества

При бюджете 200 шагов оптимизатора все три метода дают близкие результаты на downstream-наборах. AdamW остаётся сильным базовым методом по качеству: он показывает лучшие значения на ARC-Easy и PIQA, а также делит лучший результат с Hybrid на WinoGrande. Muon показывает лучший результат на ARC-Challenge по `acc_norm` и близкое качество на HellaSwag. Hybrid показывает лучший результат на HellaSwag по `acc_norm` и не демонстрирует существенной деградации качества относительно AdamW и Muon.

С учётом стандартных ошибок различия между методами на большинстве наборов невелики. Поэтому корректный вывод состоит не в утверждении абсолютного превосходства одного оптимизатора по качеству, а в том, что Muon и Hybrid сохраняют сопоставимое качество при различающемся профиле вычислительных ресурсов.

## 15. Ограничения

| Ограничение | Влияние |
|---|---|
| 200 шагов оптимизатора | Результаты отражают короткий диагностический режим, а не полноценное масштабное дообучение |
| 4,096 обучающих примеров | Использован поднабор `openwebtext-100k`, а не весь набор данных |
| Один seed | Не оценена дисперсия результатов между случайными инициализациями порядка данных |
| Обучение на Tesla T4 | Ресурсные метрики зависят от аппаратной платформы |
| Учебная реализация Muon | Нет объединённых ядер, распределённого шардинга состояний оптимизатора и аппаратно-специфичных оптимизаций |
| Нет подбора гиперпараметров Muon/Hybrid | Качество и сходимость могут измениться после поиска скорости обучения, числа итераций Ньютона—Шульца и схемы разделения слоёв |
| MeZO не реализован | Дополнительная challenge-часть задания не включена в текущую версию |

## 17. Заключение

В проекте реализован воспроизводимый конвейер полного дообучения Qwen2.5-0.5B с AdamW, Muon и Hybrid Muon+AdamW. Для каждого метода сохранены журналы обучения, гиперпараметры, контрольные точки модели, графики, проверки корректности и результаты полной оценки качества.

На текущем бюджете обучения AdamW остаётся самым быстрым и сильным базовым методом по части downstream-метрик. Muon уменьшает пиковое потребление выделенной GPU-памяти, но требует большего времени на шаг из-за ортогонализации матричных обновлений. Hybrid Muon+AdamW достигает промежуточного профиля по скорости и памяти и сохраняет сопоставимое качество модели.

Полученные результаты подтверждают корректность реализации всех обязательных конвейеров задания: AdamW, Muon, Hybrid Muon+AdamW, журналирование, сравнение ресурсов и полная оценка качества на заданных benchmark-наборах.
