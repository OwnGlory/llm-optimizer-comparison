# Сравнение AdamW, Muon, Hybrid Muon+AdamW и MeZO при полном дообучении Qwen2.5-0.5B

## 1. Аннотация

В работе реализован и экспериментально проверен воспроизводимый конвейер полного дообучения модели `Qwen/Qwen2.5-0.5B` на наборе данных `Elriggs/openwebtext-100k` с четырьмя стратегиями оптимизации:

1. AdamW;
2. Muon с резервным AdamW-обновлением для вспомогательных параметров;
3. послойный Hybrid Muon+AdamW;
4. MeZO.

Сравнение выполнено по четырём основным критериям:

- время обучения;
- максимальное потребление памяти графического процессора;
- сходимость обучения;
- итоговое качество модели на наборах PIQA, ARC-Easy, ARC-Challenge, WinoGrande и HellaSwag.

Для всех методов выполнено полное дообучение: все `494,032,768` параметров модели остаются обучаемыми. Для каждого запуска сохраняются конфигурация эксперимента, журналы обучения на каждом шаге оптимизатора, контрольная точка модели, отчёт проверки журнала, графики и результаты оценки качества.

Основной результат: в текущей постановке AdamW остаётся самым быстрым по времени шага, Muon снижает пиковое потребление памяти относительно AdamW, Hybrid Muon+AdamW даёт промежуточный компромисс между скоростью и памятью, а MeZO показывает минимальное потребление GPU-памяти, но более слабую сходимость при одинаковом бюджете 200 шагов оптимизатора.

## 5. Краткое описание алгоритмов

### 5.1 AdamW

AdamW используется как базовая стратегия оптимизации для всех обучаемых параметров модели. Оптимизатор хранит оценки первого и второго моментов градиента и применяет развязанное весовое затухание.

Упрощённая структура обновления:

```text
m_t = beta1 * m_{t-1} + (1 - beta1) * g_t
v_t = beta2 * v_{t-1} + (1 - beta2) * g_t^2
w_t = w_{t-1} - lr * m_hat / (sqrt(v_hat) + eps)
w_t = w_t - lr * weight_decay * w_t
```

### 5.2 Muon

Muon применяется к двумерным матричным параметрам Transformer-слоёв. Для каждой выбранной матрицы оптимизатор выполняет накопление импульса, нестеровскую поправку и ортогонализацию обновления с помощью итераций Ньютона—Шульца.

Упрощённая структура обновления:

```text
B_t = momentum * B_{t-1} + G_t
U_t = G_t + momentum * B_t
O_t = NewtonSchulz(U_t, steps=5)
W_t = (1 - lr * weight_decay) * W_{t-1} - lr * O_t
```

Параметры, не подходящие для матричной ортогонализации, обновляются через резервное AdamW-обновление.

### 5.3 Hybrid Muon+AdamW

Hybrid-режим реализует послойное разделение модели:

| Часть модели | Оптимизатор |
|---|---|
| Transformer-слои 0–11, выбранные двумерные матричные веса | Muon |
| Transformer-слои 12–23 | AdamW |
| Эмбеддинги, смещения, веса нормализации, `lm_head` и вспомогательные параметры | AdamW |

### 5.4 MeZO

MeZO реализован без стандартного обратного распространения ошибки. На каждом шаге генерируется случайное направление `z`, затем вычисляются два значения функции потерь при симметричных возмущениях параметров:

```text
L_plus  = L(theta + eps * z)
L_minus = L(theta - eps * z)
```

После этого оценивается направленная производная:

```text
g_hat = (L_plus - L_minus) / (2 * eps)
```

и выполняется обновление параметров вдоль случайного направления:

```text
theta = theta - lr * g_hat * z
```

В отличие от AdamW, Muon и Hybrid, MeZO не строит вычислительный граф для backward-pass и не хранит активации для обратного распространения ошибки. Это существенно снижает пиковое потребление памяти, но направление обновления получается более шумным, поэтому сходимость при коротком бюджете может быть хуже.

### 9.2 Время обучения

| Метод | Среднее время шага, сек | Относительно AdamW | Относительно Muon |
|---|---:|---:|---:|
| AdamW | 3.6750 | 1.00x | 0.54x |

AdamW является самым быстрым среди backpropagation-методов в текущей single-GPU реализации. Muon медленнее из-за явной ортогонализации Ньютона—Шульца для большого числа матричных тензоров. Hybrid сокращает вычислительные накладные расходы относительно полного Muon, так как только нижняя половина Transformer-слоёв обновляется через Muon.

MeZO показывает минимальное среднее время шага, но его шаг имеет другую вычислительную семантику: вместо `forward + backward + optimizer.step` он выполняет две прямые прогонки модели с положительным и отрицательным возмущением параметров и затем обновляет параметры по оценке направленной производной.

### 10.3 Интерпретация оценки качества

При бюджете 200 шагов оптимизатора все четыре метода дают близкие результаты на downstream-наборах. AdamW остаётся сильным базовым методом по качеству: он показывает лучшие значения на PIQA и делит лучший результат на WinoGrande. Muon показывает лучший результат на ARC-Challenge по `acc_norm`. Hybrid показывает лучший результат на HellaSwag по `acc_norm`. MeZO показывает лучший результат на ARC-Easy по `acc_norm`, но при этом имеет худшую динамику training loss.

С учётом стандартных ошибок различия между методами на большинстве наборов невелики. Muon, Hybrid и MeZO сохраняют сопоставимое downstream-качество при существенно различающемся профиле вычислительных ресурсов и сходимости.

## 11. Итоговое сравнение

| Метод | Качество | Время шага | Память | Общая характеристика |
|---|---|---|---|---|
| AdamW | Сильный baseline, лучшие PIQA и конкурентные значения на остальных наборах | Быстро среди backpropagation-методов | Наибольшая | Быстрый и стабильный базовый метод |
| Muon | Сопоставимое качество, лучший ARC-Challenge acc_norm | Самый медленный | Ниже AdamW | Меньшая память, высокая вычислительная цена ортогонализации |
| Hybrid | Сопоставимое качество, лучший HellaSwag acc_norm | Между AdamW и Muon | Между AdamW и Muon | Компромисс между скоростью и памятью |
| MeZO | Сопоставимое downstream-качество, но худшая training-сходимость | Лучшее время шага | Минимальная | Минимальная память без backward-pass, но шумная сходимость |

Основной вывод: в текущей single-GPU реализации Muon снижает пиковую выделенную память примерно на 14.0% относительно AdamW, но увеличивает среднее время шага примерно в 1.86 раза. Hybrid снижает пиковую выделенную память примерно на 7.0% относительно AdamW и при этом быстрее полного Muon примерно на 17.8%. MeZO снижает пиковую выделенную память примерно на 61.8% относительно AdamW и показывает минимальное время шага, но при бюджете 200 шагов имеет более слабую сходимость по функции потерь.

## 14. Заключение

В проекте реализован воспроизводимый конвейер полного дообучения Qwen2.5-0.5B с AdamW, Muon, Hybrid Muon+AdamW и MeZO. Для каждого метода сохранены журналы обучения, гиперпараметры, контрольные точки модели, графики, проверки корректности и результаты полной оценки качества.

На текущем бюджете обучения AdamW остаётся сильным и быстрым базовым методом среди backpropagation-подходов. Muon уменьшает пиковое потребление выделенной GPU-памяти, но требует большего времени на шаг из-за ортогонализации матричных обновлений. Hybrid Muon+AdamW достигает промежуточного профиля по скорости и памяти и сохраняет сопоставимое качество модели. MeZO демонстрирует минимальное пиковое потребление памяти и отсутствие стандартного backward-pass, но при 200 шагах показывает более слабую сходимость по training loss.

Полученные результаты подтверждают корректность реализации обязательных конвейеров задания AdamW, Muon и Hybrid Muon+AdamW, а также дополнительного challenge-компонента MeZO. Проект включает логирование по шагам, сравнение ресурсов, полную оценку качества на заданных benchmark-наборах, воспроизводимые bash-скрипты и статическую проверку качества кода.
